# 🚀 GRATISBOT
### Instant Cloud Auto-Deployer untuk Demo Tugas & Skripsi Mahasiswa

Sering mengalami masalah XAMPP error, port bentrok, atau laptop lemot saat mau demo aplikasi di depan dosen? **GRATISBOT** adalah solusinya!

---

## 💡 Apa itu GRATISBOT?

**GRATISBOT** adalah skrip otomatisasi CLI yang dibuat untuk membantu mahasiswa Informatika. Cukup jalankan **1 baris perintah** di terminal Cloud (seperti Killercoda / VPS Ubuntu), dan GRATISBOT akan mengunduh kode dari GitHub, menginstal dependensi, mengonfigurasi web server, mengimpor database, hingga menampilkan **URL Publik** yang siap didemokan.

---

## 🛠️ Teknologi yang Didukung Otomatis

- **PHP Native / CodeIgniter / Laravel** (Apache, PHP, Composer, `.env` setup)
- **Node.js / Express / React** (Node.js, NPM, PM2 Process Manager)
- **Python** (Flask / Django)
- **HTML / CSS / JS Statis**
- **Database MySQL / MariaDB** (Otomatis impor file `.sql`)

---

## 📖 Cara Penggunaan (3 Langkah Mudah)

### Langkah 1: Buka Cloud Terminal Gratis
Buka playground Ubuntu gratis di **[Killercoda Ubuntu Playground](https://killercoda.com/playgrounds/scenario/ubuntu)** (Login dengan akun GitHub).

### Langkah 2: Jalankan Command GRATISBOT
Tempelkan perintah ini di terminal Killercoda:

```bash
curl -sSL [https://raw.githubusercontent.com/FebrianSuban/gratisbot/main/gratisbot.sh](https://raw.githubusercontent.com/FebrianSuban/gratisbot/main/gratisbot.sh) | bash
```
